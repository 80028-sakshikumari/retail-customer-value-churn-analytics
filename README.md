# Retail & E-Commerce: AI-Driven Customer Value & Churn Analytics

## Project Overview

This project analyses retail transaction data to understand customer purchasing behaviour, identify high-value customer segments, and predict potential customer churn using machine learning.

The project uses Python for data cleaning, exploratory data analysis (EDA), RFM customer segmentation, churn prediction, historical customer value analysis, and interactive dashboard development.

## Objectives

- Clean and preprocess retail transaction data.
- Analyse sales trends, products, customers, and geographical revenue.
- Segment customers using Recency, Frequency, and Monetary (RFM) analysis.
- Predict customer inactivity using machine learning classification models.
- Identify high-, medium-, and low-value customers.
- Present business insights through an interactive dashboard.

## Dataset

**Dataset:** UCI Online Retail Dataset

**Source:** [UCI Machine Learning Repository – Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)

The dataset contains transaction records from a UK-based online retailer between December 2010 and December 2011.

Original dataset:
- 541,909 transaction records
- 8 columns

The original Excel dataset is not included in this repository. Download it from the source above and place it in your project folder before running the notebook.

## Project Workflow

### 1. Data Loading and Inspection
- Imported the Online Retail Excel dataset.
- Inspected dataset dimensions, columns, data types, and statistical summaries.
- Identified missing values and duplicate records.

### 2. Data Cleaning and Preprocessing
- Removed duplicate records.
- Excluded transactions without CustomerID.
- Excluded cancelled invoices.
- Removed non-positive quantities and unit prices for positive-sales analysis.
- Created a Revenue column using Quantity × UnitPrice.
- Prepared the cleaned dataset for customer-level analysis.

**Final cleaned dataset:** 392,692 transaction records.

### 3. Exploratory Data Analysis (EDA)
Analysed:
- Total revenue and customer count.
- Monthly revenue trends.
- Top 10 products by revenue.
- Country-wise revenue contribution.
- Invoice and product statistics.

### 4. RFM Customer Segmentation

Used three customer behaviour metrics:

- **Recency:** Days since the customer's last purchase.
- **Frequency:** Number of unique invoices generated by the customer.
- **Monetary:** Total historical revenue generated by the customer.

Customers were assigned RFM scores and grouped into:
- Champions
- Loyal Customers
- Potential Loyalists
- Recent Customers
- At Risk
- Lost Customers

### 5. Customer Churn Prediction

Created a 90-day inactivity-based churn target using historical and future transaction periods.

- Churn = 1: No purchase during the future 90-day observation period.
- Churn = 0: At least one purchase during that period.

Used historical Recency, Frequency, and Monetary features to train two classification models:

1. Logistic Regression
2. Random Forest Classifier

Evaluated model performance using accuracy, precision, recall, F1-score, and classification reports.

### 6. Customer Value Analysis

Calculated customer-level historical revenue and divided customers into:

- High Value
- Medium Value
- Low Value

Used percentile-based thresholds to compare revenue contribution across customer segments.

### 7. Interactive Dashboard

Created an interactive Plotly dashboard containing:
- Total revenue and customer KPIs.
- Monthly revenue trends.
- RFM customer segment distribution.
- Customer churn distribution.
- Customer value segment revenue contribution.

The dashboard was exported as an HTML file.
